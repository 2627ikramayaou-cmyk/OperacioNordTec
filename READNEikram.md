##  Lista ordenada con los pasos para subie un cambio a GutHub i una lista de tareas.
1. git status .Comprueba qué archivos de tu lista de tareas has modificado o añadido.
2. git add .Guarda y prepara todos los cambios para el envío (el punto . selecciona todo).
3. git commit -m "Explicación corta" .Registra los cambios con un mensaje corto que explique qué hiciste (por ejemplo: git commit -m "Añadida función de borrar tarea").
4. git push origin main .Sube los cambios definitivamente a tu repositorio de GitHub (cambia main por master si tu rama usa el nombre antiguo).
